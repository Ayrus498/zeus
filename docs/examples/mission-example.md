# Todo CLI

## Objective
Build a small command-line todo application in Python using only the standard library.

## Acceptance criteria
- [ ] `todo.py` supports the commands `add <text>`, `list` and `done <number>`
- [ ] Todos are persisted in a JSON file named `todos.json`
- [ ] A test file `test_todo.py` exists and its tests pass when run with `python3 -m unittest`
- [ ] A `README.md` explains how to use the tool

## Notes
Keep it simple: one module, no third-party packages.
